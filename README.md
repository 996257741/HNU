## 关于 GitHub Copilot Pro "premium requests" 限额问题说明

**问题现象：** 即使已订阅 GitHub Copilot Pro，仍然出现以下提示：

> "You have used all premium requests available this month. Upgrade your plan to increase your limit. Limit resets on April 1, 2026."

**原因说明：**

GitHub Copilot Pro 订阅包含每月一定数量的「高级请求（Premium Requests）」配额。高级请求指使用更强大 AI 模型（如 GPT-4o、Claude Sonnet 等）生成的请求，与普通请求分开计算。当本月高级请求配额耗尽后，即使是 Pro 用户也会看到此提示，这是正常的服务限制。

**解决方法：**

1. **等待配额重置：** 配额每月初自动重置（如提示所示为 4 月 1 日），重置后即可继续使用高级模型。
2. **切换到标准模型：** 在 Copilot 设置中选择使用非高级（标准）AI 模型，标准请求不受此配额限制。
3. **升级计划：** 若需更多高级请求额度，可考虑升级到 GitHub Copilot Business 或 Enterprise 计划，享有更高的月度配额。

**参考链接：** [GitHub Copilot plans and features](https://docs.github.com/en/copilot/about-github-copilot/subscription-plans-for-github-copilot)
