## GitHub Copilot 高级请求限额说明

如果您遇到以下提示：

> "You have used all premium requests available this month. Upgrade your plan to increase your limit."

**原因说明：**

即使您已订阅 GitHub Pro 计划，GitHub Copilot 也区分两种类型的请求：

1. **标准请求**：使用基础 AI 模型，Pro 计划包含无限次使用。
2. **高级请求（Premium Requests）**：使用更强大的 AI 模型（如 GPT-4o、Claude Sonnet 等），每月有固定配额限制。

GitHub Pro 用户每月有一定数量的高级请求配额，用完后需等到下月重置（通常为每月 1 日）。

**解决方法：**

- 等待配额重置（每月 1 日自动重置）。
- 升级到更高级别的 GitHub Copilot 计划（个人用户可升级至 Copilot Pro+，企业用户可选择 Copilot Business 或 Enterprise）以获得更多高级请求配额。
- 在 Copilot 设置中切换到基础模型，以继续使用标准请求（不消耗高级配额）。

更多信息请参考：[GitHub Copilot 使用限制文档](https://docs.github.com/zh/copilot/managing-copilot/monitoring-usage-and-entitlements/about-premium-requests)
